The user problem

Early signs can be easy to miss.

Crop disease felt like a tangible problem where technical tools might help make information more accessible. The opportunity was to connect image classification with an interface a person could actually use.

My ownership

Make detection usable beyond a model notebook.

I proposed and co-developed the end-to-end capstone, owned the user-facing web interface, and contributed to model development and application implementation.

Product approach

Connect the prediction to a decision.

The team worked with more than 80,000 leaf images to classify 38 crop conditions across 14 crops. I helped connect the deep learning pipeline to an interface that presents the classification in a readable way.

Outcome

A working capstone and published research.

80,000+leaf images used in the project

97%reported accuracy on the project evaluation data

I co-authored research connected to the project. The reported accuracy describes evaluation on the project dataset and does not establish performance on every field photo.
